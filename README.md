<h1 align="center">냉파를 부탁해</h1>

<p align="center">Claude와 대화하며 관리하는 우리집 냉장고·냉동실·실온 재고 앱</p>


## 무엇을 하나요

- **말로 넣고 고치기.** "두부 1모, 계란 10개 샀어", "계란 2개 먹었어", "두부 버렸어"처럼 입력하면 Claude가 재고에 반영해요. 바로 반영한 건 되돌릴 수 있어요.
- **주문 캡처로 넣기.** 쿠팡·컬리 주문 내역 캡처나 영수증 사진을 보내면, 읽은 재료를 확인 목록으로 보여 주고 고른 것만 넣어요.
- **기한 순으로 보기.** 홈에서 주요 종류별로 가장 급한 재료를 먼저 보여 주고, 전체 재고는 종류·기한·보관 장소로 묶어 볼 수 있어요.
- **있는 재료로 메뉴 추천.** 주사위를 누르면 기한이 가까운 재료를 먼저 쓰는 메뉴를 영양 정보와 함께 골라 줘요. "다 만들었어요"를 누르면 쓴 재료가 재고에서 빠져요.
- **재료 하나로 요리 찾기.** 전체 재고나 검색에서 재료를 누르면, 그 재료와 냉장고의 다른 재료로 만들 수 있는 요리를 여러 개 보여 주고, 고르면 레시피를 써 줘요.
- **우리 집 주방과 상비 재료.** 가진 조리 장비(에어프라이어, 전자레인지 등)를 적어 두면 그걸로 만들 수 있는 요리만 추천하고, 만드는 법도 그 장비 기준으로 써 줘요. 양념도 재고에 있는 것만 쓰고, 없는 재료는 따로 표시해요. 소금·간장처럼 늘 두는 재료는 "상비"로 표시해 기한 경고에서 빼요.
- **해먹은 요리.** 만든 요리가 날짜별로 쌓이고, 메뉴를 추천할 때 최근에 먹은 것과 겹치지 않게 골라 줘요. "어제 김치찌개 해먹었어"처럼 말로 남겨도 돼요.
- **기록과 백업.** 넣고 먹고 버린 내역이 날짜별 영수증처럼 쌓이고, 재고·기록·해먹은 요리·대화를 파일 하나로 내려받을 수 있어요.

## 어떻게 동작하나요

`naengpa.html` 파일 하나가 앱 전체예요. 이 파일을 내 Claude 계정에 **아티팩트**로 올리면 다음 기능이 켜져요.

| 기능 | 하는 일 |
| --- | --- |
| 저장소(DB) | 재고, 기록, 대화를 내 계정의 이 아티팩트에만 저장해요. 폰과 노트북에서 같은 내용이 보여요. |
| 페이지 안 Claude 호출 | 대화, 캡처 읽기, 레시피 추천. **내 Claude 사용량**에서 쓰여요. |
| 파일 내려받기 | 백업 파일 저장 |

서버나 API 키는 필요 없어요. 각자 자기 계정에 올리면 각자의 냉장고가 따로 생겨요.

## 설치

아티팩트를 올릴 수 있는 Claude 세션(예: 깃헙 레포를 열 수 있는 Claude)에서 이렇게 말하세요.

> wireseo/naengpa 레포의 앱을 내 아티팩트로 올려 줘

Claude는 이 레포의 [`CLAUDE.md`](CLAUDE.md)를 읽고 필요한 기능을 켜서 올려요. 올린 뒤 claude.ai에서 링크를 열면 빈 냉장고로 시작해요. 처음 열 때 Claude 사용과 파일 저장을 허용할지 물어봐요.

**처음 재고 채우기.** 앱 입력창에 장 본 것을 적거나 주문 캡처를 보내면 돼요. 집에 있는 걸 한꺼번에 목록으로 정리했다면 앱을 올린 Claude 대화에 그 목록을 붙여 넣고 "내 앱에 넣어 줘"라고 해도 돼요.

## 업데이트

> wireseo/naengpa 최신 버전으로 내 냉파 앱 업데이트해 줘

같은 링크에 새 버전이 덮어써지고, 재고와 기록은 그대로 남아요.

## 알아둘 점

- claude.ai(웹이나 앱)에 로그인한 상태로 열어야 저장과 대화가 돼요. 링크를 다른 곳에 복사해 열면 동작하지 않아요.
- 데이터는 그 아티팩트에 묶여 있어서 아티팩트를 지우면 함께 사라져요. 가끔 홈 아래의 **백업 파일 받기**로 저장해 두세요.
- 대화와 캡처 읽기는 내 Claude 사용 한도에서 빠져요. 회사 계정이면 관리자 설정에 따라 대화 기능이 꺼져 있을 수 있어요.
- 영양 정보와 추정 기한은 Claude의 추정치예요.
